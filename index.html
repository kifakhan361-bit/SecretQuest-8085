8085 Assembly Program

Explore a simple 8085 program that masks all bits except the least significant bit.

Check the Least Significant Bit

Click below to view the program and its explanation. 

LDA 2050H
ANI 01H
STA 2051H
HLT

Program Explanation

  • LDA 2050H: Loads the accumulator with the data stored at memory location 2050H.
  • ANI 01H: Performs a bitwise AND operation between the accumulator and 01H. This keeps only the least significant bit.
  • STA 2051H: Stores the result at memory location 2051H.
  • HLT: Stops program execution.

Example

If the value at memory location 2050H is 03H (binary 00000011), applying AND with 01H gives 01H (binary 00000001). The result is stored at 2051H.

Note: Assemble and execute this program in a simulator such as GNUSim8085. This website displays the code and explanation; it does not execute 8085 instructions.
