# SecretQuest — Binary Secret Decoder

SecretQuest is a web-based project that allows users to encode and decode binary messages, convert number systems, and learn about 8085 assembly language programming.

## Features
- Text to Binary and Binary to Text conversion
- Binary, Decimal, and Hexadecimal number system converter
- 8085 assembly program to check the Least Significant Bit (LSB)
- Copy output and clear input options
- Responsive and user-friendly interface

## Technologies Used
- HTML
- CSS
- JavaScript
- GNUSim8085

## How to Run
1. Open `index.html` in a web browser.
2. Use the decoder and number converter.
3. View the 8085 assembly program and its explanation.

**Note:** The 8085 program is displayed on the website and can be assembled and executed separately using GNUSim8085.
